# Siddhant Budhia

I started programming in middle school by recreating arcade games in Python. These days my projects range from modelling pressure in a cricket match to building games and tools I can use on my phone.

| Project | What to look at |
| --- | --- |
| [Cricket under Pressure](https://github.com/OrbitBoom/Cricket-under-Pressure) | A ball-by-ball analysis of T20 cricket for SupeRR Selector. The methodology and player rankings show how match context changes the meaning of a batter’s or bowler’s performance. |
| [Shroud](https://github.com/OrbitBoom/Shroud) | A top-down Python game with handcrafted rooms. The Shadow Echo mechanic lets you leave a copy behind that repeats your next attack. |
| [Pouch](https://github.com/OrbitBoom/pouch) | A mobile inbox for thoughts, links, tasks, and expenses. Captures go into a local outbox before syncing to Supabase. |
| [Lexycle](https://github.com/OrbitBoom/Lexycle) | A Hindi vocabulary app built with React Native and Expo. Turn custom word lists into spaced-repetition flashcards, quizzes, and reading practice. |

### Where I started

[Python Workshop](https://github.com/OrbitBoom/python-workshop) collects my early games and desktop experiments, revisited so they can run today. Start with **Space War** for the little orange particle bursts, or **Textpad** for a look at how much fits inside a Tkinter editor.
